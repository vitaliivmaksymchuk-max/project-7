## 3. Модульні перевірки (Native Unit Assertions)
Модульні тести ізольовані у файлі `tests.js` (підключеному через `<script src="tests.js" defer></script>`) і перевіряють чисті функції `validateTaskInput()` та `filterTasks()` за допомогою `console.assert()`. При завантаженні сторінки повідомлення `Assertion failed` у консолі відсутні.
